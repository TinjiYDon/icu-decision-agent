## 1. 开场与一句话总目标

各位老师好。我汇报的项目是 **ICU 超早期死亡风险预警协同系统**（仓库名：`icu-decision-agent`）。

**一句话总目标**：

> 在 **时间因果硬约束** 与 **stay 级公平协议** 下，为 ICU 入科后超早期时刻提供「**可决策、可校准效用、可融合、可解释、可人审**」的死亡风险预警—协同系统。

请先记住三点定位：

1. **不是**再刷一个 AUC，也 **不是**又堆一个深度网络；  
2. LightGBM 只是 **可复现的风险打分骨干**，**不是论文卖点**；  
3. 本仓的命名创新框架叫 **CUGEW**——我们提出了：  
   - **新决策指数** DEI / ANB / UEI；  
   - **新算法** RWSG（近因加权稀疏门控）；  
   - **新二级模型** SUFH（稀疏效用融合头）。

## 2. 痛点与需求

### 2.1 临床问题

ICU 入科后数小时内（预测偏移 \(h\in\{0,1,2,4,6\}\) 小时）就要判断：  
**未来 12 小时死亡风险是否值得加强监护**。  
这是稀有事件、要早决策、假阳性与漏诊代价不对称的典型决策问题。

### 2.2 五条痛点

| # | 痛点 | 后果 |
|---|------|------|
| 1 | 阳性极稀（旧 S2 ≈ **2.3%**） | 单报 ROC 几乎无决策含义 |
| 2 | 特征易混入预测时刻之后信息 | 时间泄漏 → 指标虚高 |
| 3 | 训练优化 logloss/F1，评价才画 DCA | **训练目标与临床效用错位** |
| 4 | 表格 / 时序模型「各训各测」 | 缺测时不知该信谁，不可比 |
| 5 | 解释不可追溯、不可人审 | 难进真实 CDSS 叙事 |

### 2.3 需求（三角色）

| 角色 | 需求 |
|------|------|
| 临床 / 演示 | 风险分 + 工作点建议 + 可采纳 / 驳回 |
| 学术评审 | 相对谁、改了什么、同协议指标如何更好 |
| 工程复现 | MIMIC dump 可复现、stay 级划分、主报 PR-AUC / Brier / NB / UEI |

| 块 | 回答的问题 | 主产物 |
|----|------------|--------|
| A 数据与因果 | 学的东西是否时间合法？ | feat/label、泄漏测试 |
| B 风险骨干 | 风险怎么算？ | LightGBM 多时刻分数 |

### 5.2 端到端推理（口述版）

1. 取因果特征：仅 `charttime < intime + h`；  
2. LightGBM 得当前概率 \(p^{\mathrm{cur}}\)；  
3. **RWSG**：近因加权得 \(p^{\mathrm{rw}}\)，再按完备度 \(c\) 门控；  
4. **SUFH**：用验证集训练的逻辑融合头输出 \(p^{\mathrm{SUFH}}\)；  
5. **H4**：与冻结的效用阈值 \(\tau^*\) 比较，决定是否报警；  
6. **H3**：TreeSHAP → RAG → LLM 解释，临床可采纳/驳回/编辑。

### 5.3 新旧架构对照（一页）

| 维度 | 旧流水线 | 本仓创新架构 |
|------|----------|--------------|
| 问题定义 | 单报 ROC / 粗标签 | 主报 PR-AUC / Brier / NB / **UEI** |
| 时间因果 | 易隐含泄漏 | 硬约束 \(\mathrm{charttime}<t\) |
| 分数 | 单时刻 \(p\) | \(p\) + 近因轨迹 + 融合头 |

| 多源信息 | 无或乱比 | 同 split + **RWSG/SUFH** |
| 解释 | SHAP 条或自由文本 | 引用校验 + HITL 闭环 |

## 6. 主创新 CUGEW（H6）——着重讲

> 答辩请把 **一半以上时间** 放在本节。记住三个名字：**新指数、新算法、新模型**。

### 6.1 框架定义

**CUGEW** = Causal Utility-Gated Early Warning  
在因果合法数据上，用 **效用可校准的工作点** + **完备度门控的近因融合** + **可训练二级头**，并引入 **决策效用指数族** 做主验收。

### 6.2 新指数：DEI / ANB / UEI

旧评价（ROC / PR-AUC）只回答「排得好不好」，**不回答「响警有没有超额净受益、报警是否克制」**。

在工作点 \(\tau\)、代价比 \(\lambda\) 下：

\[
\begin{aligned}
\mathrm{DEI}(\tau;\lambda)
&=\mathrm{NB}_{\mathrm{model}}-\mathrm{NB}_{\mathrm{all}}
\quad\text{超额净受益（是否优于全干预）},\\[4pt]
\mathrm{ANB}(\tau;\lambda)
&=\frac{\mathrm{NB}_{\mathrm{model}}}{\max(\mathrm{AlertRate},\varepsilon)}
\quad\text{单位报警净受益},\\[4pt]
\mathrm{UEI}(\tau;\lambda)
&=\mathrm{DEI}\cdot(1-\mathrm{AlertRate})
\quad\text{超额效用 × 选择性}.
\end{aligned}
\]

**口播要点**：答辩 **主比较报 UEI / DEI**；PR-AUC、Brier 作辅证；**不要只报 ROC**。

### 6.3 新算法：RWSG（近因加权稀疏门控）

**相对旧做法**：只用当前时刻，或对历史时刻 **均匀平均**。

**RWSG**：

1. **近因指数加权**（衰减 \(\beta\)）：

\[
p^{\mathrm{rw}}(s,h)
=\frac{\sum_{h'\le h}\mathrm{e}^{-\beta(h-h')}\,p(s,h')}
{\sum_{h'\le h}\mathrm{e}^{-\beta(h-h')}}.
\]

2. **完备度门控**（幂 \(\gamma\)）：

\[
p^{\mathrm{RWSG}}=(1-c^{\gamma})\,p^{\mathrm{cur}}+c^{\gamma}\,p^{\mathrm{rw}}.
\]

**直觉**：\(c\to 0\) 缺测多 → 信当前点；\(c\to 1\) 完备 → 更多采信近因轨迹。  
接上 Layer0 真序列后，可用 GRU-D 替换轨迹源，**门控公式不变**。

### 6.4 新二级模型：SUFH（稀疏效用融合头）

**不是**重训一个大网络替换 LightGBM。  
**是**在验证集上、仅用 meta 特征训练的 **逻辑融合头**：

\[
\mathbf{z}=\bigl[p^{\mathrm{cur}},\,p^{\mathrm{rw}},\,c,\,p^{\mathrm{cur}}-p^{\mathrm{rw}}\bigr],
\qquad
p^{\mathrm{SUFH}}=\sigma(\mathbf{w}^\top\mathbf{z}+b).
\]

| \(\mathbf{z}\) 维 | 含义 |
|-------------------|------|
| \(p^{\mathrm{cur}}\) | 当前骨干概率 |
| \(p^{\mathrm{rw}}\) | 近因轨迹概率 |
| \(c\) | 特征完备度 |
| \(\Delta p\) | 当前与轨迹分歧（趋势） |

**口播要点**：骨干负责打分；**SUFH 专门学习「当前 / 轨迹 / 完备度」怎么权衡**——这就是「新模型」的含义，系数可解释。

### 6.5 H6 主结果（旧 S2，\(h=6\)）

| 策略 | PR-AUC | Brier | DEI | UEI | 角色 |
|------|-------:|------:|----:|----:|------|
| legacy 当前时刻 | 0.164 | 0.043 | 2.365 | 2.300 | 旧基线 |
| **RWSG 门控** | **0.168** | **0.042** | 2.365 | 2.301 | 新门控算法 |
| **SUFH 融合头** | **0.177** | **0.022** | **2.410** | **2.410** | 新二级模型 |

**结论金句**：近因门控略提升排序；可训练融合头进一步提升 PR-AUC、**明显改善 Brier**，并在 **UEI 上取得最优**。

## 7. 支撑机制 H4 / H5 / H1 / H3

主创新不是孤立模块，而是嵌在整条流水线里：

> 特征合法(A) → 骨干打分(B) → **效用选阈值(H4)** → **近因门控与融合头(H6)** → **解释与人审(H3)** → 用 PR-AUC/Brier/NB/**UEI** 验收。

### 7.1 H4 · 约束效用阈值（UCEW）

**相对谁**：验证集上 max-F1，再事后画 DCA。  
**改了什么**：在验证集上按 **约束最大净受益** 选阈值。

净受益：

\[
\mathrm{NB}=\frac{\mathrm{TP}}{n}-\frac{\mathrm{FP}}{n}\cdot\lambda\cdot\frac{\tau}{1-\tau}.
\]

约束：

\[
\tau\in[0.05,\,0.40],\quad \mathrm{AlertRate}\le 0.20.
\]

**旧 S2 证据**：

| 策略 | \(\tau\) | test NB | 报警率 | PR-AUC |
|------|---------:|--------:|-------:|-------:|
| max F1 | 0.537 | −0.053 | 1.7% | 0.139 |
| **约束 max-NB** | **0.384** | **−0.035** | **2.2%** | 0.139 |
| 无约束（诊断） | 0.01 | −0.016 | 100% | 0.139 |

→ 几乎不增加报警负荷下提升净受益；**无约束会塌到 treat-all——约束是架构的一部分**。

### 7.2 H5 · 稀疏门控多时刻融合（SGDF）

H5 提出完备度门控的「当前 vs 均匀轨迹」融合；  
**H6 的 RWSG 是其升级**：轨迹由均匀平均升级为 **近因加权**，再接到 **SUFH**。

### 7.3 H1 · 精确标签叙事 + DCA

主报 PR-AUC / Brier / 净受益；DCA 回答「在哪个阈值值得响」。  
稀有阳性下 NB 可能为负，仍可能「优于全部干预」。

### 7.4 H3 · 解释可信 + HITL

TreeSHAP 结构化因子 → RAG 检索 → LLM 生成 → **引用数值校验** → 临床 **采纳 / 驳回 / 编辑** 写入审计。  
相对「只展示 SHAP 条」，把可验证引用与可驳回做成闭环。  
（演示种子 KPI：采纳率约 58% 等——标明为演示，非床旁真实周报。）

### 7.5 H2 · 公平双轨（对照纪律）

同 \(h\) / 同 stay 划分 / 同指标栈比较表格与时序；  
GRU-D labs-only 最小对照：与 LGBM 差在容差内——**不宣称时序已替换默认床旁**。

## 8. 数学公式汇总

### 8.1 符号

| 符号 | 含义 |
|------|------|
| \(s,h,t\) | stay；预测偏移小时；\(t=\mathrm{intime}+h\) |
| \(H=12\) | 标签地平线（小时） |
| \(p(s,h)\) | LightGBM 风险概率 |
| \(c(s,h)\) | 特征完备度（非空比例）∈[0,1] |
| \(\tau,a\) | 报警阈值；\(a=\mathbf{1}\{p\ge\tau\}\) |
| \(\lambda\) | 代价比（默认 4） |
| \(\beta,\gamma\) | 近因衰减；门控幂 |
| \(\pi\) | 阳性患病率 |

### 8.2 骨干（底座，非卖点）

\[
p(s,h)=\widehat{\Pr}(y=1\mid \mathbf{x}_{s,<t})=f_{\mathrm{LGBM}}(\mathbf{x}_{s,<t}).
\]

### 8.3 伪代码（部署推理）

```text
Input: stay s, hour h, λ, β, γ, frozen τ*
1  x ← features with charttime < intime+h
2  p_cur ← LGBM(x)
3  p_rw ← recency_weighted({p at h'≤h}; β)
4  c ← feature_completeness(x)
5  p_rwsg ← (1-c^γ)*p_cur + c^γ*p_rw
6  p ← SUFH(p_cur, p_rw, c)          # val-trained head
7  alert ← 1{p ≥ τ*}
8  explain ← LLM(RAG(TreeSHAP(x))); HITL feedback
9  return p, alert, explanation
```

## 12. 诚实负结果与非宣称

### 12.1 方法学负结果（加分）

1. **无约束 max-NB** → 阈值塌到极低 ≈ treat-all → 必须加窗与报警帽；  
2. **SUFH + class_weight=balanced** → 过报警、毁校准与 UEI → **默认 class_weight=None**；  
3. 稀疏子集上门控有帮助，完备子集上轨迹未必更好——**门控非万能**，要报子集分析。

### 12.2 明确不宣称

- 未外部验证 → 不写 SOTA / 首创网络；  
- TFT-lite / GRU-D **非**默认床旁；  
- 无 Layer0 → 不把多时刻表格轨迹说成「真序列深度学习」；  
- 不与 scheduling 硬耦合作为创新点；  
- 旧 S2 与 v2 **不得混表**。

## 13. 展望与收束

### 13.1 下一步（机制不变）

接 Layer0 后，在 **同一套 RWSG / SUFH / UEI 公式** 下，将轨迹源换为真序列（GRU-D 等）做同协议对照——**创新点在机制，不在换骨干品牌**。

### 13.2 收束金句（必背）

> 我们的贡献不是「用了 LightGBM」，而是提出了 **CUGEW**：  
> **新指数 DEI/ANB/UEI** 回答「值不值得响」，  
> **新算法 RWSG** 回答「多时刻怎么合」，  
> **新模型 SUFH** 回答「融合权怎么学」。  
> 在旧 S2（\(h=6\)）上，SUFH 相对当前时刻基线：  
> PR-AUC **0.164→0.177**，Brier **0.043→0.022**，UEI **2.300→2.410**。
