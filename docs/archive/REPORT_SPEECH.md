## 开场（约 30 秒）

各位老师好。我汇报的项目是 **ICU 超早期死亡风险预警协同系统**（icu-decision-agent）。

**一句话总目标**：在时间因果硬约束与 stay 级公平协议下，交付「**可决策、可校准效用、可融合、可解释、可人审**」的早期预警 CDSS——**不是再刷一个 AUC，也不是又堆一个深度网络**。

本仓的命名创新框架叫 **CUGEW**：我们提出了 **新决策指数 DEI / ANB / UEI**、**新算法 RWSG（近因加权稀疏门控）**、以及 **新二级模型 SUFH（稀疏效用融合头）**。LightGBM 只是可复现的风险打分骨干，**不是论文卖点**。

---

## 一、痛点与需求（约 45 秒）

ICU 入科后数小时内（\(h\in\{0,1,2,4,6\}\)）就要判断：未来 12 小时死亡风险是否值得加强监护。

现实难点有五条：

1. **阳性极稀**（旧 S2 约 2.3%），单报 ROC 几乎没有决策含义；  
2. 特征易混入预测时刻之后的信息，造成 **时间泄漏、指标虚高**；  
3. 训练常优化 logloss / F1，评价才画 DCA——**训练目标与临床效用错位**；  
4. 表格模型与时序模型常「各训各测」，缺测时不知道该信谁；  
5. 解释不可追溯、不可人审，难进真实 CDSS 叙事。

因此临床要的是：风险分 + 工作点建议 + 可采纳/驳回；学术要的是：相对谁、改了什么、同协议下指标如何更好。

## 二、约束（约 30 秒）——必须先讲清边界

我们主动接受这些硬约束：

- **单中心 MIMIC**；机制主表用本机 **旧 S2 dump**；当前 **无 Layer0**，真 GRU 序列后置，**不把多时刻表格轨迹说成深度学习时序**；  
- 默认床旁保持 **LightGBM**（可 TreeSHAP），GRU-D / TFT-lite 只做对照消融；  
- 本仓是 **独立 CDSS**，**不耦合**床位调度 / scheduling；  
- **未做多中心外部验证 → 不宣称泛化 SOTA / 首创网络结构**。

这些约束保证我们讲的是可复现、可证伪的机制，而不是不可审计的「调包堆模型」。

## 三、目标与价值主张（约 40 秒）

**目标**：在严格时间因果与 stay 公平协议下，交付三条能力——

1. **决策效用可量化**（该不该响、响多少）；  
2. **表格 / 多时刻融合边界可证伪**（缺测时信谁、怎么合）；  
3. **解释可追溯、可人审**（为何高风险、人能否改）。

**价值主张（不是 / 是）**：

| 不是 | 是 |
|------|----|
| 又一个更炫的深度模型 | 可复现骨干上的 **新指数 + 新门控 + 新融合头** |
| 只刷高 AUC | 稀有事件下主报 **PR-AUC / Brier / 净受益 / UEI** |
| 不可审计的 LLM 故事 | SHAP → RAG → LLM + HITL |

验收终点对应 G1–G5：预警可用、决策有用、对比诚实、解释可信、叙事自立。

## 四、主创新 CUGEW（H6）——请着重听这一段（约 2.5–3 分钟）

下面进入本项目的 **主创新点 CUGEW**。请记住三个名字：**新指数、新算法、新模型**。

### 4.1 新指数：DEI / ANB / UEI

旧评价只看 ROC 或 PR-AUC，回答的是「排得好不好」，**不回答「响警有没有超额净受益、报警是否克制」**。

我们在工作点 \(\tau\)、代价比 \(\lambda\) 下定义：

- **DEI**（超额净受益）= 模型净受益 − 全干预净受益 —— 是否真的优于「全员加强监护」；  
- **ANB**（单位报警净受益）= 模型净受益 / 报警率 —— 每一声报警值不值；  
- **UEI**（选择性效用指数）= DEI × (1 − 报警率) —— 把「超额效用」和「少报警」写进同一个可比较指数。

**答辩主比较请报 UEI / DEI**；PR-AUC、Brier 作辅证。不要只报 ROC。

### 4.2 新算法：RWSG（近因加权稀疏门控）

旧做法往往是：只用当前时刻分数，或对历史时刻 **均匀平均**。

我们提出 **RWSG**：

1. 对 \(h'\le h\) 做 **近因指数加权**（越近权重越大，衰减系数 \(\beta\)）；  
2. 再用特征 **完备度** 做门控：缺测多时回退当前点，完备时更多采信近因轨迹。

相对均匀轨迹，这是更合理的多时刻融合机制；公式与门控在接上 Layer0 真序列后 **仍然成立**。

### 4.3 新二级模型：SUFH（稀疏效用融合头）

我们不是「再训一个大网络替换 LightGBM」。

**SUFH** 是在验证集上、用 meta 特征训练的 **逻辑融合头**（二级决策模型）：

输入向量包含：当前概率、近因轨迹概率、完备度、以及二者之差；  
输出 \(p=\sigma(w^\top z+b)\)。

骨干 LGBM 只负责打分；**SUFH 专门学习「当前点 / 近因轨迹 / 完备度」怎么权衡**——系数可解释、可汇报，这就是「新模型」的含义。

### 4.4 旧 S2 真跑证据（h=6）

| 策略 | PR-AUC | Brier | UEI |
|------|-------:|------:|----:|
| 旧·当前时刻 | 0.164 | 0.043 | 2.300 |
| RWSG | 0.168 | 0.042 | 2.301 |
| **SUFH** | **0.177** | **0.022** | **2.410** |

结论一句话：**近因门控略提升排序；可训练融合头进一步提升 PR-AUC、明显改善 Brier，并在 UEI 上取得最优。**

方法学诚实负结果（加分项）：若 SUFH 使用 class_weight=balanced，会过报警、毁校准——因此默认 **不用 balanced**，已写入方法。

## 五、支撑机制（约 1 分钟）——此前要求一并交代

主创新之外，流水线还有三条支撑假设，保证「分数算完之后真能决策」：

### H4 · 约束效用阈值（UCEW）

相对「验证集上 max-F1 再事后画 DCA」，我们在验证集上按 **约束最大净受益** 选阈值（代价比默认 FP:FN=1:4，加阈值窗与报警帽）。

旧 S2：阈值 0.537→**0.384**；test 净受益 **−0.053→−0.035**；报警约 1.7%→2.2%；PR-AUC 保持 0.139。  
无约束会塌到 treat-all——**约束本身是架构的一部分**。

### H5 · 稀疏门控多时刻融合（SGDF）

H6 的 RWSG 是在其完备度门控思想上的升级：由均匀轨迹升级为近因加权，再接到 SUFH。

### H1 / H3 · 决策评价与解释可信

- **H1**：精确标签叙事 + DCA，主报 PR-AUC / Brier / 净受益；  
- **H3**：TreeSHAP → RAG → LLM，引用校验 + HITL 采纳/驳回，解释可审计。

整条链是：

> 特征合法 → 骨干打分 → **效用选阈值（H4）** → **近因门控与融合头（H6）** → **解释与人审（H3）** → 用 PR-AUC / Brier / NB / **UEI** 验收。
