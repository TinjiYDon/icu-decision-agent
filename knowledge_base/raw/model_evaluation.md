# 模型评估指标详解：ROC-AUC、PR-AUC、Brier Score

## ROC-AUC（受试者工作特征曲线下面积）

【适用：区分度评估】

**定义**：
ROC曲线以假阳性率（FPR=1-特异度）为横轴，真阳性率（TPR=灵敏度）为纵轴，绘制所有分类阈值下的性能。AUC取值0.5-1.0。

**解读标准**：
- 0.5 = 随机猜测（无区分能力）
- 0.7-0.8 = 可接受
- 0.8-0.9 = 优秀
- >0.9 = 卓越

**局限性**：
- 对类别不平衡不敏感：正样本率2.34%时，AUC=0.779可能高估实际性能
- 假阳性率在极端情况下被稀释：特异度从99.5%到99.9%的改善在ROC上几乎不可见
- 不能直接反映临床实用价值

**本项目数据**：
- Train ROC-AUC = 0.779（test集相同量级）
- 提示模型具有中等偏上的区分能力

来源：Hand DJ, Till RJ. Stat Methods Med Res. 2001;10(2):113-152.

## PR-AUC（精确率-召回率曲线下面积）

【适用：极端类别不平衡场景】

**定义**：
PR曲线以召回率（Recall=TPR）为横轴，精确率（Precision=TP/(TP+FP)）为纵轴。AUC取值0-1。

**为何在极端不平衡时更重要**：
- 当正样本率仅2.34%时，随机模型的PR-AUC≈0.023
- AUC=0.779对应的PR-AUC≈0.139，意味着在所有预测为正的患者中，约13.9%实际为阳性
- PR-AUC对少数类的识别能力更敏感

**解读参考**：
- PR-AUC > 正样本率 = 模型优于随机
- PR-AUC ≈ 2×正样本率 = 模型有一定实用价值
- 本项目PR-AUC=0.139 ≈ 6×正样本率（0.023），说明模型有较好的少数类识别能力

**本项目数据**：
- Test PR-AUC = 0.139
- 对比随机基线（0.023），模型有约6倍的相对提升

来源：Saito T, Rehmsmeier M. PLoS One. 2017;12(2):e0172584.

## Brier Score（布里尔分数）

【适用：概率校准评估】

**定义**：
Brier = (1/n) × Σ(pred_i - actual_i)²
取值0-1，0=完美校准，1=最差校准。

**解读**：
- <0.1 = 良好校准
- 0.1-0.25 = 可接受
- >0.25 = 较差

**与AUC的互补性**：
- AUC衡量排序能力（谁会死），Brier衡量概率准确性（死的可能性多大）
- 一个模型可以有高AUC但糟糕的校准（系统性高估或低估风险）
- Brier score = (AUC相关项) + (校准偏差项) + (分辨率项)

**本项目数据**：
- Test Brier = 0.040 → 良好校准
- 意味着预测概率与真实发生率大致吻合

来源：Brier GW. Mon Weather Rev. 1950;78(5):1-3.

## 校准曲线与DCA（决策曲线分析）

【适用：临床效用评估】

**校准曲线**：
- 将预测风险分为10等份（deciles）
- 每份计算平均预测风险和实际事件率
- 理想情况下点应落在45度线上
- 本项目需补充： calibration slope, calibration intercept

**DCA（Decision Curve Analysis）**：
- 评估不同阈值概率下的净收益（net benefit）
- NB(threshold) = (TP - FP × threshold/(1-threshold)) / n
- 比较：全治疗 vs 模型指导 vs 不治疗
- 阈值概率范围：0.05-0.50（覆盖临床决策 range）

来源：Vickers AJ, Elkin EB. Med Decis Making. 2006;26(1):56-67.
