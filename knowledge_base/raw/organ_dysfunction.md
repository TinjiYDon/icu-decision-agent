# 多器官功能障碍综合征（MODS）与脓毒症相关器官衰竭

## MODS 概念与诊断标准

【适用：ICU多器官功能评估】

**定义**（1991 ACCP/SCCM共识）：
器官功能障碍是指机体不能维持内环境稳定的状态，需要干预以维持正常功能。
MODS = 两个或以上器官系统序贯或同时发生功能障碍。

**器官系统功能障碍标准**：

| 器官 | 功能障碍标准 |
|------|------------|
| 呼吸 | PaO2/FiO2 <300（急性肺损伤）；<200（ARDS） |
| 肾脏 | 肌酐 >2.0 mg/dL 或尿量 <500 mL/d |
| 肝脏 | 胆红素 >2.0 mg/dL |
| 血液 | 血小板 <100×10³/μL |
| 心血管 | MAP <70 mmHg 或需血管活性药 |
| 神经 | GCS <10（或镇静中断后无法评估） |
| 胃肠 | 应激性溃疡出血、肠蠕动消失 |

**时序特征**：
- 序贯性：一个器官衰竭后相继出现其他器官衰竭
- 第一次器官衰竭后，后续器官衰竭风险增加约3倍/器官
- 器官衰竭数与死亡率呈指数关系：1个器官≈20%，2个≈40%，3个≈60%，≥4个≈80%

来源：Bernard GR, et al. Chest. 1992;101(6):1644-1655.

## 脓毒症相关性急性肾损伤（SA-AKI）

【适用：脓毒症肾损伤机制与预测】

**KDIGO 2012 AKI分期**：
- Stage 1：肌酐升高1.5-1.9倍基线 或 尿量<0.5 mL/kg/h × 6-12h
- Stage 2：肌酐升高2.0-2.9倍基线 或 尿量<0.5 mL/kg/h × ≥12h
- Stage 3：肌酐升高≥3.0倍基线 或 肌酐≥4.0 mg/dL 或 开始RRT 或 尿量<0.3 mL/kg/h × ≥24h

**脓毒症AKI的特殊性**：
- 肾血流 redistributed（皮质→髓质），肾素-血管紧张素-醛固酮系统激活
- 炎症介质（TNF-α、IL-6）直接损伤肾小管上皮细胞
- 乳酸堆积导致肾血管收缩和ATP耗竭
- SOFA肾脏评分与AKI分期高度相关

**预测价值**：
- BUN >60 mg/dL 是脓毒症AKI的独立预测因子
- 肌酐每升高1 mg/dL，死亡率增加约15%
- 本项目的BUN特征与AKI风险强相关

来源：Kidney Disease: Improving Global Outcomes (KDIGO) AKI Work Group. Kidney Int Suppl. 2012;2(1):1-138.

## 脓毒症相关脑病（SAE）与GCS解读

【适用：脓毒症神经损伤评估】

**定义**：
脓毒症相关脑病（SAE）是脓毒症最常见的神经系统并发症，表现为意识障碍、认知功能下降和脑电图异常。

**临床特征**：
- GCS下降是SAE的早期标志（敏感度90%）
- 谵妄发生率：ICU脓毒症患者20-87%
- 脑灌注压（CPP）<60 mmHg 与不良预后相关

**神经保护策略**：
- 维持MAP≥65 mmHg以保证脑灌注
- 避免低氧血症（SpO2≥94%）
- 控制体温（目标36-37.5°C）
- 合理使用镇静药物（RASS目标-2至0）

**GCS在SOFA中的作用**：
- GCS 15分 → SOFA神经0分
- GCS 13-14 → SOFA神经1分
- GCS 10-12 → SOFA神经2分
- GCS 6-9 → SOFA神经3分
- GCS <6 → SOFA神经4分（气管插管）

来源：Jin Y, et al. Front Neurol. 2022;13:834378.

## 脓毒症相关凝血病（SIC）评分

【适用：脓毒症凝血功能障碍】

**SIC（Sepsis-Induced Coagulopathy）评分标准**：
- 血小板 ≤150×10³/μL：1分；≤100：2分；≤50：3分；≤20：4分
- INR >1.5：1分；>2.0：2分；>3.0：3分；>5.0：4分
- 纤维蛋白原 <2 g/L：1分；<1 g/L：2分
- DIC评分 ≥5分 = DIC诊断

**与本项目关联**：
- 本项目lab_inr特征对应SIC评分的INR维度
- 本项目vasopressor_1h反映了凝血病严重程度（DIC常伴血管活性药需求）
- 血小板计数（本项目未直接使用）是SOFA凝血评分的核心

来源：Levi M, et al. Intensive Care Med. 2009;35(11):1856-1864.

## 脓毒症肝损伤（SIL）与胆红素

【适用：脓毒症肝脏功能障碍】

**定义**：
脓毒症相关肝损伤（SIL）表现为胆汁淤积和肝细胞损伤，是SOFA肝脏评分的基础。

**临床特点**：
- 胆红素升高是脓毒症肝损伤最敏感的指标
- 转氨酶（ALT/AST）轻度升高（通常<5倍正常上限）
- 严重脓毒症时可能出现"休克肝"（ ischemic hepatitis）
- 乳酸清除能力下降是肝损伤的早期标志

**与本项目关联**：
- 本项目未直接使用胆红素特征（可能因数据缺失率较高）
- BUN作为肾功能指标，与SOFAs肾脏维度对应
- 未来可扩展胆红素作为肝脏功能特征

来源：Motoyama CY, et al. Minerva Anestesiol. 2014;80(9):1039-1051.
