# 血流动力学与液体复苏临床指南（SSC 2021 / J-SSCG 2024 完整版）

## 脓毒性休克液体复苏（SSC 2021）

【适用：脓毒性休克患者】

**初始液体复苏**：
- 脓毒性休克：30分钟内开始静脉晶体液复苏，初始剂量30 mL/kg
- 液体选择：平衡盐溶液（Lactated Ringer's）优先于生理盐水
- 监测：每30分钟评估血流动力学反应（MAP、尿量、乳酸清除）

**液体反应性评估**：
- 被动leg raise（PLR）试验：SV变化>15%预示液体反应性好
- 脉压变异度（PPV）>13%（机械通气患者）预示液体反应性
- 下腔静脉变异度（IVC-V）>18%预示液体反应性
- 休克指数（SI=HR/NIBP）>0.9提示容量不足或心功能不全

**血管活性药物选择**（SSC 2021第14条推荐）：
- 首选去甲肾上腺素（Norepinephrine）：起始剂量0.1 μg/kg/min，目标MAP≥65 mmHg
- 去甲肾上腺素无效时：加用血管加压素（Vasopressin）≤0.03 U/min
- 右旋糖酐去甲肾上腺素时：加用多巴胺（Dopamine）
- 肾上腺素作为二线选择
-  Dobutamine用于心肌功能障碍（LVEF<40%）

**目标**：
- MAP ≥65 mmHg（目标导向治疗）
- 尿量 ≥0.5 mL/kg/h
- 乳酸恢复正常或下降趋势

来源：Evans L, et al. Crit Care Med. 2021;49(11):e1-e34.

## 血流动力学监测指标详解

【适用：ICU血流动力学评估】

**平均动脉压（MAP）**：
- MAP = (SBP + 2×DBP) / 3
- 目标：≥65 mmHg（脓毒性休克）
- <65 mmHg：器官灌注不足，AKI/脑缺血风险增加
- >110 mmHg：靶器官损害风险增加

**中心静脉压（CVP）**：
- 正常范围：2-8 mmHg
- CVP指导液体复苏的价值存在争议（ProCESS、ARISE、ProMISe试验）
- 趋势监测优于单次绝对值

**心脏指数（CI）**：
- 正常范围：2.5-4.0 L/min/m²
- 脓毒性休克早期：高动力状态（CI>4.0），晚期：低动力状态（CI<2.5）

**混合静脉血氧饱和度（SvO2）**：
- 正常范围：65-75%
- <60%：组织氧摄取增加或氧供减少（休克状态）
- >80%：微循环障碍或细胞毒性缺氧

**乳酸廓清率**：
- 廓清率 = (初始乳酸 - 复查乳酸) / 初始乳酸 × 100%
- 6小时廓清率≥20%与生存率提高相关
- 但绝对乳酸值比廓清率更具预测价值（部分研究争议）

## 休克指数（Shock Index）临床解读

【适用：血流动力学快速评估】

**定义与计算**：
SI = 心率（bpm）/ 收缩压（mmHg）

**分度标准**：
- 0.5-0.7：正常
- 0.7-0.9：临界（需密切监测）
- 0.9-1.5：休克状态（死亡率显著升高）
- >1.5：危重休克（极高死亡风险）

**临床预测价值**：
- SI >0.9预测院内死亡率（OR=2.5-5.0）
- SI >1.0预测输血需求（AUC=0.76）
- SI与乳酸呈强正相关（r=0.465-0.91）
- MSI（HR/MAP）对ICU入住预测价值更好（AUC=0.75）

**SqSOFA**：
qSOFA + SI组合形成SqSOFA，AUC=0.694 vs qSOFA单独0.631
适合院前/急诊快速筛查

来源：Fukuda T, et al. J Emerg Med. 2017;52(1):39-45.
来源：Surendhar S, et al. Afr J Thorac Crit Care Med. 2023.

## 血管活性药剂量与监测

【适用：脓毒性休克血管活性药管理】

**去甲肾上腺素（首选）**：
- 起始：0.1 μg/kg/min
- 目标：MAP≥65 mmHg
- 最大：0.5 μg/kg/min（超过此剂量死亡率显著升高）
- 监测：心律失常、肢端缺血（皮肤花斑）

**血管加压素（二线联合）**：
- 剂量：0.03 U/min（固定剂量，非滴定）
- 作用：节约去甲肾上腺素剂量
- 监测：缺血并发症、低钠血症

**多巴胺（替代选择）**：
- 仅用于低心律失常风险患者
- 剂量：2-20 μg/kg/min
- 监测：心律失常、高血糖

**肾上腺素（三线）**：
- 剂量：0.01-0.5 μg/kg/min
- 监测：乳酸升高（β2受体效应）、心律失常

**正性肌力药物（Dobutamine）**：
- 适应证：心肌抑制（LVEF<40%）
- 剂量：2-20 μg/kg/min
- 监测：低血压、心动过速

来源：Evans L, et al. Crit Care Med. 2021;49(11):e1-e34.

## 液体选择与容量管理

【适用：ICU液体管理】

**晶体液 vs 胶体液**：
- 晶体液（首选）：生理盐水、平衡盐溶液（Lactated Ringer's）
- 白蛋白：在脓毒性休克中可能有益（ALBIOS试验），但证据等级中等
- 羟乙基淀粉（HES）：不推荐使用（肾脏损害风险）

**限制性vs积极性液体策略**：
- 脓毒性休克早期：积极性液体复苏（30mL/kg）
- 复苏后：采取较保守的液体策略（FAN-TASS试验）
- 过量液体与AKI、ARDS、肠水肿相关

**液体平衡监测**：
- 正平衡>5L与死亡率增加相关
- 每日液体平衡记录是标准护理实践
- 利尿剂促进液体负平衡可改善AKI预后（部分研究）
